### [ICANN to Terminate Third-Level .name Domains](https://neil.fraser.name/news/2026/09/03/) ⭐️ 8.0/10

ICANN has decided to terminate existing third-level .name domains \(e.g., \`x.y.name\`\) and subsequently release the corresponding second-level domains \(e.g., \`y.name\`\) for new registration. This policy change has generated significant debate, with critics raising concerns about internet stability, the potential for domain squatting, and whether the decision aligns with ICANN&\#x27;s mission to ensure stable and secure internet identifier systems. The termination specifically affects third-level registrations, not second-level .name domains like \`dvt.name\`.

hackernews · pavel\_lishin · Sep 3, 14:54 · [Discussion](https://news.ycombinator.com/item?id=49550772)

**「Background」** The .name top-level domain \(TLD\) was designed to offer personalized internet addresses, supporting both second-level domains \(e.g., example.name\) and third-level domains \(e.g., john.doe.name\). ICANN, the Internet Corporation for Assigned Names and Numbers, is a non-profit organization that oversees the internet&\#x27;s unique identifier systems, including domain names, and has the authority to approve policy changes such as the termination of specific domain levels.

**「Impact」** Users who currently own third-level .name domains will lose their registrations, and the corresponding second-level domains face a risk of domain squatting once released.

**「Community Discussion」** Community members generally view the termination of existing third-level .name domains as problematic, with concerns raised about the policy contradicting ICANN&\#x27;s mission for stable and secure internet operations and the potential for domain squatting. There was also a clarification that only third-level domains are affected, not second-level .name registrations.

### [Porting 1993 Amiga Game to Godot with LLM Reading 68000 Assembly](https://babyloniantwins.com/blog/porting-a-1993-amiga-game-to-godot/) ⭐️ 8.0/10

An author successfully ported their 1993 Amiga game, &quot;Babylonian Twins,&quot; originally written in MC68000 assembly, to Godot using Claude Fable 5. The initial port took an evening, with further weekends and evenings spent on refinement. The LLM assembled the code using \`vasm\` to achieve byte-identical binaries, accounting for a 108-byte mismatch due to the original \`AsmOne\` saving a running game&\#x27;s memory snapshot. This project highlights AI&\#x27;s powerful capabilities in modernizing legacy code and reverse engineering.

**「Context」** The game &quot;Babylonian Twins,&quot; a puzzle-platformer, was originally developed in Baghdad in 1993 for the Amiga personal computer, utilizing MC68000 assembly language. It holds the distinction of being the first commercial video game made in Iraq. The project involved porting this legacy game to Godot, a modern open-source game engine, with the assistance of an LLM \(Large Language Model\) named Claude Fable 5.

**「Impact」** This achievement demonstrates a significant advancement in AI&\#x27;s capacity to understand and translate complex, low-level legacy code, offering a promising path for software preservation and modernization efforts.

**「Community Discussion」** Community members expressed awe at the original game&\#x27;s creation in 1993 assembly, noting the difficulty of debugging without modern resources. ### [Proposing JEPA-based World Models in Simulation to Ground LLM Physics Understanding](https://www.reddit.com/r/MachineLearning/comments/1w69gvd/grounding_llms_with_jepabased_world_models/) ⭐️ 8.0/10

A Reddit user proposed a novel method to ground Large Language Models&\#x27; \(LLMs\) understanding of physics by training a JEPA-style world model within physics simulations like MuJoCo. This model would predict abstract representations of future physical states, forcing it to learn core principles such as object permanence and momentum, rather than merely statistical token relationships. The learned physical intuition would then be attached to an LLM as a conditioning signal, aiming to provide a computational primitive for physical reasoning and accelerate downstream learning. The author notes that while V-JEPA and DreamerV3 explore similar concepts, this specific combination of simulation-grounded JEPA representations with LLM attachment appears novel, raising questions about implementation and the sim-to-reality gap.

reddit · r/MachineLearning · /u/Full\_Promotion4522 · Sep 3, 14:45

**「Context」** Large Language Models \(LLMs\) excel at linguistic tasks but lack a &quot;grounded&quot; understanding of the physical world, meaning they process statistical relationships between words without true intuition about concepts like physics. World models are AI systems designed to build internal representations of an environment, simulating its dynamics, such as physics and causality, to predict how it changes over time. Joint Embedding Predictive Architectures \(JEPA\) are a family of self-supervised models that learn robust representations by predicting future states in an abstract embedding space, rather than raw sensory data, and have been applied to various modalities including video \(V-JEPA\) and world modeling.

**「Impact」** If successful, this approach could equip LLMs with a genuine, grounded understanding of physical principles, enabling them to perform tasks requiring real-world physical intuition more effectively than current models relying solely on linguistic patterns.

### [Microsoft to Enable Memory Integrity Protection by Default on Windows 11 in October 2026](https://techcommunity.microsoft.com/blog/windows-itpro-blog/expanding-memory-integrity-protection-across-windows-devices/4551984) ⭐️ 8.0/10

Microsoft plans to enable Memory Integrity Protection \(HVCI\) by default on eligible Windows 11 devices starting October 13, 2026. This security feature leverages hardware virtualization to create an isolated environment, ensuring only trusted kernel-mode code and drivers can execute, thereby reducing the risk of malicious programs hijacking devices via low-level drivers. Devices must support hardware virtualization, UEFI, and Secure Boot for HVCI to activate. While enhancing security, this change may prevent activation on systems with old or incompatible drivers, and in rare cases, could lead to blue screen errors.

telegram · zaihuapd · Sep 3, 06:09

**「Background」** Memory Integrity Protection \(HVCI\) is a Windows security feature that utilizes hardware virtualization to isolate critical system processes from potential threats. By creating a secure, isolated environment, HVCI ensures that only verified and trusted kernel-mode code and drivers are allowed to run, significantly bolstering the operating system&\#x27;s defense against sophisticated malware and rootkits. This isolation prevents malicious software from gaining control over the system&\#x27;s core components.

**「Impact」** This default enablement will significantly enhance the security posture of compliant Windows 11 devices against advanced threats like malicious driver hijacking, though it may necessitate driver updates or hardware upgrades for some users to maintain compatibility.
