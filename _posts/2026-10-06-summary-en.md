Previously, Cowork ran model inference in the cloud but executed tool calls within an Anthropic-provided VM shipped to the user&\#x27;s device, which caused local resource drain, performance issues, and work interruption upon closing a laptop. Its initial architecture involved running AI model inference in the cloud while executing tool calls within a virtual machine \(VM\) that was deployed locally on the user&\#x27;s computer.

**「Impact」** Cowork users will benefit from significantly reduced local resource consumption, continuous work execution regardless of device state, and expanded accessibility to the tool from mobile devices.

### [Rust \`chunkr\` Library Offers Significant Speedup for Text Chunking](https://www.reddit.com/r/MachineLearning/comments/1wyfruw/a_chunking_lib_in_rust_that_is_20x_faster_p/) ⭐️ 8.0/10

A new open-source Rust library, \`chunkr\`, has been released, offering significantly faster text chunking capabilities for AI/ML and NLP workflows compared to existing Python-based alternatives. Benchmarks on an MBA M4 16GB show \`chunkr\` achieving throughputs like 2,264 MB/s for recursive chunking \(1 MB, 1000/200\), outperforming LangChain \(769 MB/s\) and LlamaIndex \(10 MB/s\), and 750 MB/s for fixed character chunking \(1 MB, 1000/200\) against LangChain&\#x27;s 1.7 MB/s. The library, developed by /u/Ok\_Cartographer5609, supports various strategies including Character, Recursive, Markdown header, and Hierarchical chunking, alongside a native PDF loader that is up to 15.9x faster than \`pypdf\`.

**「Background」** Text chunking is a preprocessing technique in natural language processing \(NLP\) and machine learning \(ML\) that involves dividing large documents into smaller, manageable segments or &\#x27;chunks.&\#x27; This process is crucial for applications like Retrieval Augmented Generation \(RAG\) systems, where it helps improve the efficiency and relevance of information retrieval by breaking down content into units suitable for embedding and search. Existing frameworks such as LangChain and LlamaIndex provide tools for text chunking, offering various strategies to segment text.

**「Impact」** Software engineers and ML practitioners can achieve substantial performance gains in text preprocessing for AI/ML and NLP applications, particularly for Retrieval Augmented Generation \(RAG\) systems, by integrating the \`chunkr\` library.

### [Distilling Stockfish Value Function into Neural Networks with 1 Billion Positions](https://www.reddit.com/r/MachineLearning/comments/1wxz5qq/distilling_stockfish_on_a_billion_positions_full/) ⭐️ 8.0/10

A project successfully distilled the Stockfish chess engine&\#x27;s value function into ResNet/ViT models using 1 billion positions from the Gigafish dataset, aiming to approximate depth-limited search faster than Stockfish itself. The full 3.9 billion position dataset, derived from 37 months of Lichess games, is now publicly available on Hugging Face under the name \`lukesalamone/gigafish-3.8b-d10\`. Key architectural findings indicate that while CNNs were initially more effective due to their geometric inductive biases, combining CNNs with Vision Transformers yielded the best overall results for this task. This work explores the potential for neural networks to compete with existing small neural nets like NNUE by approximating complex search functions.

reddit · r/MachineLearning · /u/microscope1024 · Oct 5, 04:11

**「Background」** Stockfish is a powerful, open-source chess engine that has evolved from using hand-crafted evaluation functions to primarily employing neural networks, including the Efficiently Updatable Neural Network \(NNUE\), for board position assessment. NNUE is a neural network architecture specifically designed to enhance the evaluation speed and efficiency of alpha-beta searchers in board games like chess. ResNet \(Residual Network\) is a type of Convolutional Neural Network \(CNN\) commonly used in computer vision, while Vision Transformers \(ViT\) apply the Transformer model&\#x27;s self-attention mechanism to image data, offering an alternative to traditional convolutional approaches.

**「Impact」** The release of the 3.9 billion position Gigafish dataset provides a substantial resource for the machine learning community, while the architectural insights into CNN and Vision Transformer performance offer valuable guidance for developing game AI.
