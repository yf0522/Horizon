**「Impact」** This breakthrough allows previously restricted CMP 170HX cards to function as powerful AI accelerators, providing a more accessible hardware option for AI tasks like LLM inference and image generation, significantly impacting the second-hand GPU market and potentially offering a cost-effective alternative to A100 GPUs.

### [ML Reviewer Advocates Desk Rejection for Papers Lacking Reproducible Code](https://www.reddit.com/r/MachineLearning/comments/1vei12v/its_time_to_desk_reject_papers_that_dont_include/) ⭐️ 8.0/10

A machine learning conference reviewer, having evaluated 12 papers across three major conferences this year, observed a concerning lack of reproducible code in submissions. Only one paper provided full, runnable code, four offered partial code fragments, and seven provided no code at all, severely hindering quality assurance and reproducibility. The reviewer noted that three of the five papers with any code contained obvious bugs that invalidated their results, highlighting the critical impact of hidden errors. To address this issue and change current incentives, the reviewer advocates for a policy of desk-rejecting papers that do not include runnable code capable of reproducing the reported results.

reddit · r/MachineLearning · /u/Flaky-Ambition5900 · Aug 3, 16:17

**「Context」** NeurIPS \(Conference on Neural Information Processing Systems\) is a prominent annual conference in artificial intelligence and machine learning. While NeurIPS does not strictly mandate code release, its guidelines strongly encourage submitting code for experimental results and new datasets to facilitate reproducibility, with submitted code kept confidential during the review process.

**「Impact」** Adopting a policy to desk-reject machine learning papers lacking reproducible code would compel researchers to provide runnable implementations, directly improving the transparency and quality of published results by enabling verification and bug detection.
