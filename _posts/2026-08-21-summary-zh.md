### [安全研究员意外记录数十万军事基地电话](https://lina.sh/blog/hijacking-e164-arpa) ⭐️ 8.0/10

一位安全研究员意外发现 e164.arpa 电话路由系统中存在一个长期存在的漏洞，该漏洞允许记录数十万通电话，其中包括拨往军事基地的电话。这一发现揭示了关键基础设施中持续存在的安全缺陷，以及传统系统漏洞的顽固性。此事件对个人隐私和国家安全构成了重大影响，凸显了对电信系统进行持续安全审计的必要性。

hackernews · gavide · 8月21日 13:11 · [社区讨论](https://news.ycombinator.com/item?id=49387570)

**「背景」** ENUM（电话号码映射）是一种将 E.164 格式的电话号码映射到互联网地址的系统。它通过在互联网域名系统 \(DNS\) 中查询 \`e164.arpa\` 域来实现，该域专门用于电话号码映射。具体来说，一个电话号码会被转换为一个特殊的域名，然后 DNS 会返回 NAPTR 记录，这些记录指示如何通过 VoIP/SIP 等互联网协议联系到该号码。

**「影响」** 此漏洞的发现直接导致了包括军事基地在内的电话通话记录被意外收集，对受影响用户的隐私和国家安全构成了实际风险。

**「社区讨论」** 社区讨论指出，e164.arpa 系统并非完全废弃，仍在私有领域用于号码携号转网服务，并对作者未因此事面临法律问题表示惊讶。评论者还强调了此类漏洞长期未被发现的普遍性，以及军事机构牵涉其中才促使问题得到解决的现象。

### [LLM 输出简洁性研究：指令式压缩输出可省钱，压缩输入则否](https://www.reddit.com/r/MachineLearning/comments/1vulfei/does_telling_an_llm_to_be_concise_actually_save/) ⭐️ 8.0/10

一项针对九个大型语言模型（LLM）的实证研究表明，指示模型生成简洁输出能显著降低成本（平均节省 1.5 倍，最高达 3 倍），同时保持准确性，且跨语言有效。研究测试了 GPT-4o、GPT-5.4、Claude Haiku 4.5、Claude Sonnet 4.6 等模型，涵盖五种缩减级别、五个短答案数据集、十一种语言及长篇摘要任务。相反，压缩输入提示不仅未能节省成本，反而可能导致成本增加高达 96%并降低准确性，因为模型会生成更长的回答来弥补被削减的信息。研究还发现，输出 token 的成本高于输入 token，因此减少输出 token 在短单轮任务中能节省成本；此外，约一半的简洁正确输出与模型在无约束条件下的推理过程不符，但这对于只关心最终答案的场景通常是可以接受的。尽管提供商提供的“简洁输出”选项是否能节省成本尚不明确，但通过 API 自行控制提示确实能实现成本节约。

reddit · r/MachineLearning · /u/ibubbles34 · 8月21日 16:38

**「背景」** 大型语言模型（LLM）的运行成本通常基于处理的 token 数量，包括用户输入的提示（input tokens）和模型生成的响应（output tokens）。提示工程是指导 LLM 行为的关键技术，其中包含的指令会影响模型的响应长度和内容，进而直接影响其计算资源消耗和成本。

**「影响」** 对于通过 API 直接使用大型语言模型的开发者和组织而言，这项研究提供了明确的成本优化策略，即通过指令要求模型生成更简洁的输出，从而在不牺牲准确性的前提下显著降低运营成本。

### [医院寻求本地 MLOps 生产监控方案，应对自建及第三方模型漂移与偏见挑战](https://www.reddit.com/r/MachineLearning/comments/1vut9wm/onprem_mlops_in_a_hospital_advice_needed_for/) ⭐️ 8.0/10

一家医院正在其本地 OpenShift 集群上构建一个自助式 MLOps 平台，以支持多个团队开发预测模型，同时遵守 MDR \(EU 2017/745\) 和欧盟 AI 法案等严格法规。尽管 ClearML 和 OpenShift AI 在开发和部署方面表现良好，但医院发现它们在生产监控方面存在不足，尤其是在数据漂移、偏见检测、实时仪表板、自定义指标和不可变推理日志记录方面。该医院面临的独特挑战是，需要为运行在供应商基础设施上的第三方模型提供一致的监控，这些模型只能通过输入/输出数据流进行访问，这促使他们寻求能够统一处理这两种场景的解决方案。

reddit · r/MachineLearning · /u/zentax2001 · 8月21日 21:30

**「背景」** MLOps（机器学习运维）是一套实践，旨在将机器学习模型从开发阶段高效地部署到生产环境并进行维护。在医疗保健领域，由于涉及敏感的患者数据和直接影响临床决策，MLOps 需要特别关注模型的可靠性、公平性、可解释性和合规性，以满足如欧盟医疗器械法规\(MDR\)和欧盟人工智能法案等严格的法律要求。

**「影响」** 该医院的经验凸显了在高度监管的医疗环境中，现有 MLOps 平台在提供全面、统一的生产模型监控方面的局限性，这可能促使行业对更强大的监控工具和标准的需求，尤其是在处理第三方 AI 服务时。

### [中国发改委修订对外投资管理办法征求意见稿，收紧资金出境管控](https://yyglxxbsgw.ndrc.gov.cn/htmls/article/article.html?articleId=2c97d16c-9ff00a63-01a0-230bacc4-0001) ⭐️ 9.0/10

中国国家发展改革委发布了《对外投资管理办法（修订征求意见稿）》，旨在显著强化资金出境管控，具体措施包括扩大安全审查范围至存量资产转让、增加金融机构连带责任、强制报告重大不利情况以及对境外再投资和返程投资实施穿透监管。

telegram · zaihuapd · 8月21日 13:05

**「背景」** 此次修订征求意见稿将取代 2017 年发布的《企业境外投资管理办法》，反映了中国政府对境外投资监管政策的进一步收紧。

**「影响」** 这些收紧的规定将增加中国企业和金融机构对外投资的审查和复杂性，特别是涉及与美国实体进行跨境交易的企业，并可能影响考虑将制造业迁出中国的公司。
