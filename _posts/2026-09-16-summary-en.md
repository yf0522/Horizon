### [Security Firm Gains Admin Access to Baseten GitHub via Exposed Token](https://www.strix.ai/blog/baseten-harbor-github-pat-takeover) ⭐️ 8.0/10

This token provided admin and push access to critical repositories, including Baseten&\#x27;s main product, GitOps, and Homebrew tap, alongside read/write access to other private customer-specific repositories. The incident underscores a significant software supply chain security vulnerability, particularly relevant for MLOps platforms and broader software engineering practices.

hackernews · bearsyankees · Sep 15, 18:11 · [Discussion](https://news.ycombinator.com/item?id=49716476)

**「Background」** Baseten is an MLOps platform primarily focused on model serving and inference, enabling ML engineering teams to deploy and optimize custom machine learning models in production. A GitHub Personal Access Token \(PAT\) is an alternative to using a password for authentication to GitHub, often used for command-line access or automation, and can grant various levels of access to repositories. Docker build history records the layers and commands used to create a Docker image, which can inadvertently expose sensitive information if not properly managed.

**「Impact」** This incident demonstrates how an exposed personal access token can lead to full administrative control over a major MLOps platform&\#x27;s production repositories, posing a severe software supply chain security risk for Baseten and its customers.

**「Community Discussion」** The community acknowledged Baseten&\#x27;s prompt response in rotating the token and securing the Harbor project after the report. ### [SHADOW-50M: A 44M Parameter Quantized LLM for Efficient On-Device AI](https://www.reddit.com/r/MachineLearning/comments/1wgzpli/i_trained_a_44m_parameter_quantized_llm_from/) ⭐️ 8.0/10

A developer trained SHADOW-50M, a 44M parameter quantized Large Language Model \(LLM\) from scratch on 45 billion tokens, achieving a 19.8 MB model size and approximately 1,900 tokens/second inference on a laptop CPU with 41 MB RAM. This efficiency is enabled by novel techniques including ternary \{-1,0,+1\} weights and a 73,880-token vocabulary represented by fixed 512-bit fingerprints, allowing for direct vocabulary expansion without retraining. SHADOW-50M integrates fixed circuits for tasks like arithmetic and date calculations, and features a unique disk-based persistent memory system for rapid factual retrieval, demonstrating strong performance in these specialized areas despite lower scores on general benchmarks compared to larger models. The project explores the potential for highly deployable, offline AI, exemplified by its integration into a talking Peppa Pig plush toy, highlighting its focus on useful behavior in tiny local models.

reddit · r/MachineLearning · /u/Final-Data-1410 · Sep 15, 12:59

**「Background」** Large Language Models \(LLMs\) are deep learning models trained on vast amounts of text data to understand and generate human-like text. Quantization is a technique used to reduce the precision of model weights, often from floating-point to lower-bit integers, significantly decreasing model size and improving inference speed, which is crucial for deploying LLMs on resource-constrained devices.

**「Impact」** This development concretely demonstrates that highly optimized, small-parameter LLMs can deliver practical, specialized capabilities for on-device and offline applications, such as efficient factual retrieval and complex calculations, without relying on cloud services or large computational resources.
