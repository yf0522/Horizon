A new research paper, &quot;Functional Gradient Descent with Adaptive Representations,&quot; has been accepted at NeurIPS, introducing a novel approach to functional gradient descent. This method addresses the challenge of infinite-dimensional functional gradients by formalizing &quot;adaptive representations,&quot; which provably ensure convergence to global minimizers. **「Impact」** This research provides a robust and provably convergent optimization method that could substantially improve the performance and reliability of machine learning and AI models, potentially leading to more efficient and accurate solutions in various applications.

### [GLM5.3 Sparse Attention Optimizes HBM Memory Usage](https://newsletter.semianalysis.com/p/sparse-savings-persistent-demand-inside-glm53) ⭐️ 8.0/10

The article explores how GLM5.3 utilizes sparse attention and other advanced optimization techniques to significantly impact High Bandwidth Memory \(HBM\) usage. It details the role of methods such as KV Cache Offloading, HiSparse, DeepSeek Sparse Attention, and IndexShare in enhancing memory efficiency. These optimizations are crucial for reducing the HBM footprint of large language models, which is vital for their efficient and cost-effective deployment. The analysis also considers the implications of Single-rollout Asynchronous Optimization in this context.

rss · Semianalysis · Sep 28, 19:26

**「Background」** Sparse attention is an optimization technique for large language models that reduces computational complexity and memory usage by selectively attending to relevant parts of the input sequence, particularly beneficial for long contexts. KV cache offloading complements this by moving attention key/value data from high-cost GPU memory to more affordable storage like CPU memory or disk, thereby freeing up GPU resources and enabling more efficient scaling of LLM workloads.

**「Impact」** These memory optimizations directly enable organizations to deploy large language models with lower HBM hardware requirements and reduced operational costs.
